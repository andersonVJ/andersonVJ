## 🚀 Proyecto Destacado

### [StockVision](https://github.com/andersonVJ/StockVision) — Plataforma SaaS de Gestión Inteligente de Inventarios
- Arquitectura desacoplada **React + Django REST Framework**, orientada a un modelo multiempresa (SaaS) para PYMES.
- Más de 10 módulos funcionales: inventarios, productos, proveedores, usuarios, roles y dashboard administrativo con reportes.
- Autenticación **JWT** y documentación de API con **Swagger/OpenAPI**.
- Módulo de predicción de demanda con **XGBoost y Prophet**.
- Despliegue en producción con **Docker, Dokploy, Nginx** sobre **PostgreSQL**.
- 🔗 Demo: [app.stockvision.site](https://app.stockvision.site) | Repo: [github.com/andersonVJ/StockVision](https://github.com/andersonVJ/StockVision)
